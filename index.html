UX + HCI

Uma interface deve considerar as pessoas

UX (User Experience) busca criar experiências úteis, simples e agradáveis. Já HCI (Interação Humano-Computador) estuda a maneira como as pessoas interagem com sistemas computacionais.

Quando esses conceitos são combinados com acessibilidade, podemos desenvolver produtos digitais que atendam a uma quantidade maior de pessoas.
